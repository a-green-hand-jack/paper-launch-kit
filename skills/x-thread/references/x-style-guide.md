# X（Twitter）学术圈风格指南

适用：AI/ML 研究者在 X 上发布论文。都是社区惯例与经验，不是平台官方规则。

## 这个平台的生态

- **受众是同行**：研究者、工程师、学生、AI 媒体号、投资人。他们刷得很快，第一条推文决定是否点开 thread。
- **传播靠转发链**：导师、合作者、大 V 的转发/引用决定了能跑多远。thread 写得好不如被对的人转。
- **英文为主**。中文圈同行也在 X 上，但用英文写能覆盖全部人。
- **配图/视频是必须的**：纯文字的论文推几乎没有曝光。动图/短视频（demo、生成结果对比）通常比静态图表现更好。
- **外部链接**：普遍观察是带外链的帖子分发受限，因此惯例是**链接放在 thread 最后一条**（不放第一条）。
- **免费账号单条上限 280 个加权字符**：英文字母算 1，中日韩文字和 emoji 算 2，任何 URL 固定算 23。用 `check_x.py` 校验。

## Thread 结构（首发，5–8 条）

| # | 作用 | 要点 |
|---|---|---|
| 1 | **钩子** | 一句话说清"做到了什么"，最好带一个具体数字或反直觉结论；附 teaser 图/视频；结尾 `🧵👇` 或 `(1/n)`。必须能单独成立——很多人只看这一条。 |
| 2 | 问题 | 为什么现有方法不行，痛点要具体。 |
| 3 | 核心想法 | 一句话直觉 + 方法图。不要堆公式。 |
| 4–5 | 结果 | 每条一个结果、一张图。数字精确到论文原值。 |
| 6 | 意外发现/分析 | 可选。"我们还发现……"是很好的互动点。 |
| 7 | 局限/展望 | 可选，一句话，增加可信度。 |
| 末 | 链接 + 致谢 | Paper / Code / Project page 链接；@ 合作者与导师；感谢单位。 |

**钩子的写法**（选一种，别用"We are excited to announce"这种空话开头）：
- 结论先行：`Can a 1B model match 7B on X? Turns out yes — with one trick. Introducing NAME 🧵`
- 数字先行：`NAME cuts training cost by 4.2x while matching accuracy on 6 benchmarks.`
- 反常识：`Everyone assumes X. We found the opposite.`
- 演示先行：一段 demo 视频 + `NAME does X from a single Y.`

"Excited to share" 不是禁止，但放在数字/结论之后，不要开头。

## 其他帖子类型

- **中稿**：引用转发首发 thread：`NAME is accepted to VENUE 2026 🎉 See you in CITY!`，可加一张新图。
- **参会**：`I'll present NAME at VENUE — Poster #123, Hall X, Thu 10:30–12:30. Come say hi!` + 海报缩略图 + 主页链接。
- **新版本/开源**：单条 + GIF/视频 + 链接。

## 细节

- **@ 谁**：只 @ 作者本人（合作者、导师）。不 @ 无关的大 V 求转发——会被视为骚扰。
- **话题标签**：0–1 个（如会议标签 `#NeurIPS2026`）。X 上标签多显得像营销号。
- **配图**：横图 16:9 或 2:1 最稳；图里的字要在手机上可读（放大字号或裁剪局部）。每张图写 alt text（无障碍，也是好习惯）。
- **语气**：自信但克制。不说 "SOTA crushes all baselines" 这种话，用数字说话。避免 "revolutionary" "game-changer"。
- **表情符号**：每条最多 1–2 个，用来做视觉分隔（🧵 📄 💻 🌐），不是情绪表达。
- **发布时间**：美东上午（周二至周四最佳），即北京时间晚上。
- **发完之后**：置顶该 thread；把 thread 链接私发合作者/导师请他们转发；前 1–2 小时回复评论。

## 手动发 thread 的方法（免费）

1. 在 x.com 网页或 App 点发帖，粘贴第 1 条，上传图片。
2. 点"+"添加下一条，依次粘贴（post-kit.html 里每条都有复制按钮）。
3. 全部填好后点"全部发布"。约 3 分钟。

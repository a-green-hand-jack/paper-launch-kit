# 小红书科研内容风格指南

适用：AI 方向博士生在小红书分享自己的论文/项目/科研经历。都是平台惯例与经验观察，平台规则会变，以 App 实际为准。

## 这个平台的生态（和 X 完全不同）

| | X | 小红书 |
|---|---|---|
| 受众 | 同行研究者 | 学生、工程师、准备读研读博的人、对 AI 好奇的普通人；少量同行 |
| 用户在找什么 | 新论文、新结果 | 经验、干货、真实的人和故事、"能学到点什么" |
| 内容单位 | 文字串 + 图 | **图文卡片轮播**（图是主体，文字是补充）或竖屏视频 |
| 分发 | 关注 + 转发链 | **算法推荐 + 搜索**。很多人把小红书当搜索引擎用 |
| 第一眼 | 第一条推文 | **双列信息流里的封面图 + 标题** |
| 语气 | 专业、克制 | 第一人称、口语化、真诚、讲人话 |
| 外链 | 放最后 | **基本不能放**，会影响流量 |

结论：小红书上不是"翻译 X thread"，而是**以一个真实博士生的身份，用一组好看的卡片，讲一个外行也能看懂的故事**。

## 笔记的组成

### 1. 封面（最重要，决定点击）

信息流是双列的，封面在手机上只有约半屏宽，所以：
- 3:4 竖图（1080×1440）。
- **大字**：2–3 行，总共 ≤ 15 字，字要粗、要大，关键词用高亮色/底色标出。
- 一个视觉锚点：论文 teaser 图的最直观部分，或作者本人照片（海报前合影、工位）。真人出镜通常点击更高，但需要用户提供照片并愿意露脸。
- 角落小标签说明内容类型，如「AI 论文分享」「顶会中稿」「读博日常」。
- 不放密密麻麻的英文图表当封面。

### 2. 卡片（第 2–N 张，建议总共 6–9 张）

- 每张卡**只讲一个点**，一个大标题 + 一张图 + ≤ 3 行短句。
- 字号要大：正文 ≥ 40px（在 1080 宽的画布上），标题 ≥ 64px。手机上读不清的卡等于没有。
- 所有卡片统一模板、统一配色——形成辨识度，以后每个项目都用同一套，就是个人品牌。
- 推荐顺序：
  1. 封面
  2. 一句话说清"这篇做了什么"（外行版）
  3. 为什么这个问题重要 / 生活里的例子
  4. 核心想法（类比 + 简化的方法图）
  5. 效果（大数字 + 一张对比图）
  6. 一个有意思的发现或幕后故事（如果用户提供了）
  7. 信息卡：论文名、会议、arXiv 编号、"GitHub 搜 xxx"、作者单位
- 英文论文图可以用，但要加中文标注或中文标题解释它在说什么。

### 3. 标题（≤ 20 字，硬限制）

- 要有**搜索关键词**（大模型、AI、论文、顶会名、读博、具体方向如"具身智能"）。
- 要有**情绪或钩子**。常见句式：
  - `读博第三年，终于中了第一篇 NeurIPS`（经历型）
  - `一张图看懂：我们怎么让大模型少算 4 倍`（干货型）
  - `AI 论文分享｜让机器人看一眼就会叠衣服`（分享型）
  - `顶会中稿｜分享我的 rebuttal 经验`（经验型）
- 可以用「｜」分隔类型标签和内容。
- 不做标题党：标题里的数字和说法必须和 brief 一致。

### 4. 正文（≤ 1000 字，硬限制；建议 300–600 字）

- 第一人称（"我们组""我"），像跟朋友讲。
- 短段落，段与段之间空行。用 emoji 做小标题或列表符号（📌 💡 ✅ 🔗），每段最多 1 个。
- 结构：开头一句钩子 → 背景 → 我们做了什么（外行版）→ 效果 → 一句个人感受或幕后（用户提供的）→ 结尾一个提问引导评论（如"你们觉得 AI 什么时候能真正做家务？"）。
- 结尾放话题标签。

### 5. 话题标签（5–10 个）

宽泛 + 垂直 + 具体组合，例如：
`#人工智能 #AI #大模型 #深度学习 #论文分享 #科研 #读博 #博士日常 #NeurIPS #具身智能`
发布时在 App 里输入 # 会出现已有话题，选已存在的话题，不自造冷门标签。

## 会被限流/降权的东西（务必避开）

- **外部链接**、二维码、微信号/QQ 号/邮箱、"私信领取""评论区扣 1 发你"之类导流话术。
  → 想让人找到论文：信息卡上写 **论文全名 + arXiv 编号 + "GitHub 搜 项目名"**，让用户自己搜。
- 引导去其他平台（"去 B 站/X 看完整版"）。
- 广告法极限词："最""第一""顶级""最强""唯一""国家级"等。学术上的 "first" 在小红书改写成"之前还没有人这样做过"这类表述，并确保 brief 支持。
- 搬运他人内容。发自己的工作，发布时勾选**原创声明**。
- 新号短时间内大量发布、批量操作、使用自动化工具频繁登录——都可能被判异常。

## 发布时间

北京时间工作日 12:00–13:00、18:00–22:00；周末下午到晚上。与 X 的最佳时间（美东上午 = 北京晚上）正好重合，可以同一晚发。

## 账号经营（长期）

- 固定人设：如"AI 方向博士生，分享科研日常和自己的论文"。主页简介写清方向和学校（用户自己决定公开到什么程度）。
- 不只发论文：论文之间可以穿插读博日常、开会见闻、工具推荐、投稿经验——这些往往比论文本身更容易火，也让论文笔记有人看。本 kit 可以按同一套卡片模板生产这类笔记。
- 评论区的问题要回，回复也算互动。

## 手动发布（免费，约 3 分钟）

- 手机：把 `launch/xhs/cards/*.png` 传到手机（AirDrop/微信文件传输/网盘），App 里点 "+" → 选图（按序号顺序）→ 粘贴标题、正文 → 添加话题 → 勾选原创声明 → 发布。
- 电脑：小红书创作服务平台（creator.xiaohongshu.com）网页版可直接上传图片发布图文，并支持定时发布。
